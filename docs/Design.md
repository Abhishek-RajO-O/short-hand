# Design & UI Guidelines

## 1. Color Palette
The application uses a high-contrast, modern dark-themed palette:
*   **Dark Navy (Backgrounds):** `#222831`
*   **Dark Grey (Secondary Backgrounds/Cards):** `#393E46`
*   **Gold/Yellow (Accents/Primary Actions):** `#FFD369`
*   **Off-White (Text/Foreground):** `#EEEEEE`

## 2. Typography & Theming
*   Use standard, clean sans-serif fonts (e.g., Inter, Roboto, or system defaults).
*   Respect system-level light/dark mode preferences where applicable, though the default brand identity leans toward the provided dark palette.

## 3. UI Layouts
*   **Popup Interface:** A compact, vertical layout featuring a header, a search input, a list of templates showing the shortcut and a text preview, and a prominent primary button anchored at the bottom.
*   **Dashboard Interface:** A spacious, full-screen layout with a left navigation sidebar, a central area for large template cards (displaying full text, tags, and actions), and global controls like search and filtering at the top.
