# Development Roadmap

*   **Phase 1:** Foundation (React + Vite + Tailwind + Manifest V3 setup).
*   **Phase 2:** Basic Popup (Initial UI, message count, navigation links).
*   **Phase 3:** Persistent Storage (Wrapper service around `chrome.storage.local`).
*   **Phase 4:** Message CRUD (Create, Read, Update, Delete UI and logic).
*   **Phase 5:** Categories (Create, select, filter, and delete categories).
*   **Phase 6:** Shortcut Expansion (Core logic for replacing `;trigger` with text).
*   **Phase 7:** ChatGPT Website Integration (Injecting expansion logic into target site).
*   **Phase 8:** Unknown Shortcut Notification (UI prompt for unregistered triggers).
*   **Phase 9:** Import / Export (JSON data handling).
*   **Phase 10:** Search / Autocomplete (Dashboard search and input suggestions).
